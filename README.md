# Sports to People — Free Website

This is a static legal/support website for Sports to People.

## Free hosting option: GitHub Pages
GitHub Pages can host static HTML/CSS/JS on GitHub Free.

1. Create a free GitHub account.
2. Create a public repository, for example `sports-to-people-site`.
3. Upload all files in this folder to the repository root.
4. In GitHub: Settings → Pages.
5. Choose “Deploy from a branch”, select `main` and `/root`.
6. Save.
7. GitHub will provide a public `github.io` URL.

## Alternative
Cloudflare Pages also supports static HTML and provides a free `pages.dev` address.
